# 0007. Новые имена записей журнала, прежние читаются

## Контекст

Прежние расширения пишут записи `pi-codex-goal*` и `context-compaction*`. Их читают Recall и `pi-scenarios`. Решение Р5: новое расширение пишет под своими именами, старые записи читает.

## Решение

Новые записи получают приставку `goal-compact`. Каждая запись несёт поле `version`. Читатель журнала понимает и прежние записи нынешнего формата целиком, а более старые — только для показа (решение Р1). Каталог документов цели — `.pi/goal-compact/`.

Имена событий, по которым с расширением общаются соседи, не меняются: `pi-recall:goal-reply`, события `pi-subagents`, скрытые сообщения PiRetry.

## Альтернативы

- **Писать под прежними именами.** Отклонено решением Р5: после отката старая пара читала бы записи нового формата, которых не понимает.

## Последствия

- Откат — две строки настроек; цель, созданную новой версией, старая пара не увидит.
- Recall и `pi-scenarios` правятся при переключении.

## Не входит

Перенос существующих журналов в новый формат не делается.

## Проверка

Тесты чтения старых журналов: сессия с незакрытой целью старой пары открывается, продолжается и закрывается (сценарий Б5).

## Статус

Принято.
