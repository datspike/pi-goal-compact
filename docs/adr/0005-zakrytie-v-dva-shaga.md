# 0005. Закрытие цели в два шага по версиям договорённости и плана

## Контекст

В одной из долгих сессий цель закрылась по проверке, сделанной до последней правки. Проба возврата договорённости при первой попытке закрытия вернула модель к работе в двух случаях из двух.

## Решение

Первая попытка `update_goal(complete)` для данной пары «редакция договорённости, версия плана» не закрывает цель: возвращает договорённость и неподтверждённые пункты «Решаю сам» и просит назвать доказательство по каждому пункту «Готово, когда». Вторая попытка при той же паре закрывает цель, если есть отчёт `verifying` для этой же пары и выполнены прежние условия. Любая правка договорённости или плана обнуляет оба условия.

Правка договорённости и смена состояния пункта «Решаю сам» принимаются только в прогоне, начатом или дополненном настоящей репликой владельца.

## Альтернативы

- **Проверять наличие возврата без версий.** Отклонено: поломка `ignoreRevisions` показывает закрытие по устаревшей сверке.

## Последствия

- Закрытие стоит одного лишнего вызова; ложные отказы проверяются сценарием Н2.
- Агент в автономной работе не может переписать цель под сделанное.

## Не входит

Смысл правки расширение не судит (требование Т7.2).

## Проверка

Модель `formal/Agreement.tla`, свойства П8 и П9; поломки `ignoreRevisions`, `noVerifying`, `noOwnerCheck`.

## Статус

Принято.
