# 0006. С чистого листа — ядро; листовые модули переносятся с тестами

## Контекст

Владелец просил архитектуру «с чистого листа», чтобы решение было чистым и читаемым, и запретил терять поведение. Около 12 тысяч строк прежних расширений — это и автомат, и модули, которые не зависят от порядка событий: разбор сводки, файловые наводки, бюджет сжатия, проверка языка, рабочая стадия со скоростью генерации.

## Решение

С нуля пишутся ядро (решение 0001), обвязка Pi и сборка окна. Листовые модули переносятся вместе с их тестами и причёсываются: имена, язык комментариев, границы импорта. Поведение листовых модулей меняется только по требованию с номером.

## Альтернативы

- **Переписать всё.** Отклонено: поведение, живущее только в коде листовых модулей, — главный способ его потерять.
- **Перенести всё.** Отклонено: переносит и смешение решений с вводом-выводом.

## Последствия

- Перенесённые тесты — доказательство сохранения поведения по строкам реестра.
- Разрыв зависимостей: листовые модули не импортируют ядро и обвязку; проверяется `npm run lint:arch`.

## Не входит

Кандидаты К1–К3 и К7–К9 удаляются по решению Р6 и не переносятся.

## Проверка

Перенесённые тесты в `test/`; правило слоёв в `.dependency-cruiser.cjs`.

## Статус

Принято.
