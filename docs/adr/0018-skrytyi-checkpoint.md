# 0018. Инструмент самосжатия скрыт по умолчанию

## Контекст

Триггеры и правила полезного самосжатия ещё не продуманы. По исходным данным владельца за месяц не было ни одного вызова инструмента; самостоятельный аудит журналов в эту работу не входит. Постоянно объявлять схему модели ради такого использования нецелесообразно.

## Решение

В существующий блок features файла goal-reports.json добавлен checkpointCompactContinue со значением false по умолчанию. Флаг читается при загрузке расширения. При false инструмент не регистрируется вообще, а не только исключается из активного набора. Для возврата задать {"features":{"checkpointCompactContinue":true}} глобально или в .pi/goal-reports.json проекта и перезагрузить расширение командой /reload либо перезапустить Pi в каталоге проекта. Проект перекрывает глобальную настройку по одному полю.

## Альтернативы

Удалить инструмент — усложнило бы проверку будущих сценариев. Оставить включённым — постоянные расходы на недоказанную возможность. Добавить новый механизм настроек — избыточно при существующих features.

## Последствия

По умолчанию схема и указания инструмента не передаются модели. Код инструмента и старые записи остаются читаемыми. Смена ветки не меняет регистрацию: после изменения флага требуется перезагрузка расширения.

## Не входит

Автоматическое сжатие по порогу и переполнению, команда /compact, события session_before_compact/session_compact, сводки и продолжения цели не меняются. Диета схем Goal пока только исследуется. Полезные сценарии экономного самосжатия отложены в приватной карточке.

## Проверка

Тест checkpoint-feature проверяет отсутствие регистрации и объявления при false, включение при true и обработчики штатного сжатия при обоих значениях. Существующие тесты сжатия проверяют порог, переполнение и ручной путь независимо от объявления инструмента.

## Статус

Принято. Уточняет доступность инструмента из решения 0003, не меняя маршрут сжатия.
