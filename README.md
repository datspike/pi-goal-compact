# pi-goal-compact

[English version](README.en.md)

Расширение [Pi](https://github.com/badlogic/pi-mono), которое ведёт долгую работу к цели через много окон контекста и сжимает контекст так, чтобы замысел владельца не терялся по дороге.

> **Состояние: в разработке.** Расширение пока ничего не регистрирует в Pi. Пользоваться им рано.

## Зачем

Долгая работа агента живёт дольше одного окна контекста. При каждом сжатии история заменяется пересказом, и после нескольких сжатий агент работает уже по собственному пересказу пересказа: исходные слова владельца в окне не остаются. Работа при этом не останавливается, она понемногу уходит в сторону.

Ведение цели и сжатие контекста решают одну задачу — довести работу до того, о чём договорились. Поэтому здесь это одно расширение, а не два, которые согласуют между собой, что модель увидит в начале окна.

## Происхождение

Расширение продолжает [pi-codex-goal](https://github.com/datspike/pi-codex-goal) и [context-compaction](https://github.com/datspike/context-compaction) и заменяет оба. Подробности — в [NOTICE](NOTICE).
