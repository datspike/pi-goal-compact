# Формальная проверка

Здесь будут лежать небольшие модели автомата расширения на TLA+ и навык, по которому их проверяют при изменении кода. Модели пишутся вместе с решениями об архитектуре, до кода ядра.

Модели проверяют механику: что скрытое продолжение одно, что ожидание владельца держит, что договорённость в окне модели есть и одна. Поведение самой модели-агента они не проверяют.
